## 现有系统

梦游迹小程序仓库在本机，Git 没有配置 GitHub 远程地址。

| 层 | 实际 |
|---|---|
| 客户端 | 微信小程序 |
| 后端 | 微信云函数。故事入口是 `storyEngine`，身份是微信 `OPENID` |
| 数据库 | 微信云开发文档库 |
| 照片 | 微信云存储 |

这套不能直接当成 WorldAsGame.com 的登录和数据库。浏览器用户没有 `OPENID`。

小程序继续用云开发。云数据库不迁移，海外访客不写进微信用户表。

## 网站以后用的三样

都先走免费额度。只在准备部署时开通。

| 用途 | 选择 |
|---|---|
| 域名 | Cloudflare 只负责 WorldAsGame.com 的 DNS |
| 网站进程 | Node。密码哈希、会话、订单和付款确认都在这个进程里。Cloudflare Workers 和 Pages 跑不了当前的 `argon2` |
| 海外进度 | 一个 Neon PostgreSQL。生产环境必须设置 `DATABASE_URL`，不能靠本机 `.data/` |
| 照片 | Cloudflare R2。数据库只存地址和哈希。第一集照片还没做，所以现在不必开通 |

不同时开通 Supabase、Neon 和 D1。不用 GitHub Pages 做这个商业网站。Vercel 的个人免费方案不用于正式商用。用户、进度、订单和照片不放进 Git 仓库。

代码可以放到 GitHub，用来保存版本和触发 Cloudflare 部署。GitHub 不是数据库。

电影视频还没有。第一集是文字、一个选择和一张照片，先不为视频准备流量。以后视频进 R2，不进 Git。

## 两边怎么共用

共用的是故事规则：未结束的局可以续上，受保护进度只有服务端能写，同一次任务只推进一次，旧存档不能覆盖新存档。

规则放在仓库里的独立模块。云函数和网站接口各调一份。账号关联做成之前，两边的进度各存各的。

## 付款上线前要问 PayPal 的事

账户是中国大陆企业账户。上线真实扣款前确认：

1. 是否已开通网站 Standard Checkout。
2. 是否允许销售在线互动故事和数字解锁。
3. 买家能否不登录 PayPal、直接用银行卡。
4. 当前美元收款费率。
5. 美元余额如何结算到国内银行。订阅不在第一笔里问。

退款、重复通知和「付了款但页面关了」都由服务端处理。第一版可以不接这些，只保留未解锁占位。
