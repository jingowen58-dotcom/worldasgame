# 网站框架方案

> 2026-11-17。这一阶段只搭房子。剧情、选择、拍照、账号和付款都以后再装进去。  
> 确认后才写代码。本文不是开发完成记录。

## 1. 这一阶段做完是什么样

用手机打开本地网站，能看到 World As Game 的外壳：

- 顶栏是站名，底栏能去到隐私和条款。
- 首页只有一个故事位，写明第一部还没开放。不放假的作品列表，不放第一集正文。
- 播放、任务、登录这三条以后要用的路径已经存在。现在打开它们，只会说明功能还没开放，不会出现表单提交或剧情。
- 页面是英语。没有数据库，没有登录，没有图片上传。

域名 WorldAsGame.com 写在页脚和页面信息里。这一阶段不要求已经解析到线上。

## 2. 技术

| 项 | 选择 |
|---|---|
| 应用 | Next.js（App Router）+ TypeScript |
| 样式 | Tailwind CSS |
| 文案 | 一个英语字典文件。以后加语言时只加文件，不把句子写死在组件里 |
| 运行 | 先在本机跑。部署留到框架验收之后 |
| 数据 | 无 |

目录：

```text
app/
  layout.tsx          全站顶栏、底栏、页面信息
  page.tsx            首页
  stories/page.tsx    故事列表，当前只有未开放的一位
  play/[runId]/page.tsx
  tasks/[challengeRunId]/page.tsx
  login/page.tsx
  privacy/page.tsx
  terms/page.tsx
components/
  SiteHeader.tsx
  SiteFooter.tsx
  StorySlot.tsx
lib/
  site.ts             站名、域名、导航
  copy/en.ts          界面英语
```

故事以后从 `StorySlot` 和 `/play` 接进去。框架不读取 Ink，不调用小程序云函数。

## 3. 页面

界面英语用下面的意思。正式句子写在 `lib/copy/en.ts`，这里只定每页的职责。

| 路径 | 现在显示 | 以后接入 |
|---|---|---|
| `/` | 站名、一句「故事发生在你的世界里」、一个未开放的故事位、开始按钮不可进入剧情 | 故事开放后，按钮进入 `/play` |
| `/stories` | 同上这一部，状态是未开放 | 有多部时才增加条目 |
| `/play/[runId]` | 说明故事还没开放 | 服务端返回的正文和选择 |
| `/tasks/[challengeRunId]` | 说明任务还没开放 | 照片提交 |
| `/login` | 说明保存进度还没开放。没有输入框 | 邮箱链接 |
| `/privacy` | 短页面，标明文案未最终审阅 | 正式隐私政策 |
| `/terms` | 短页面，标明文案未最终审阅 | 正式条款 |

首页不出现 The Other Side、Jordan Hale、Evelyn，也不出现邮件正文。这些还没确认，不能做成已经上线的故事。

导航只留 Stories。播放页以后再加返回和进度，这一阶段播放页没有自己的一套导航。

手机优先：单列，首屏能看见站名和故事位，不出现横向滚动。宽屏只是把同一列居中，不另做一套桌面首页。

视觉用一套可替换的默认值，不当成最终品牌设计：

| 用途 | 值 |
|---|---|
| 背景 | `#101412` |
| 表面 | `#1C2420` |
| 正文 | `#F0F1EC` |
| 次要文字 | `#A6B1A9` |
| 按钮 | `#D8E0D4`，按钮文字 `#101412` |
| 字体 | 系统无衬线字体 |

没有海报、没有视频、没有标志图形。

## 4. 明确不放进框架

- 剧情正文、选项、Ink、故事版本。
- 数据库、游客 Cookie、邮箱登录。
- 拍照、对象存储、付费、PayPal。
- 角色对话、证据板、分享卡。
- 小程序进度。
- 多语言正文。字典只留英语界面。
- 线上部署、DNS、Neon、R2。框架在本机验收通过后再做。

## 5. 验收

本机用手机宽度和桌面宽度各看一遍：

1. `/`、`/stories`、`/play/preview`、`/tasks/preview`、`/login`、`/privacy`、`/terms` 都能打开。
2. 页与页之间能从顶栏、底栏走通。
3. 没有任何按钮声称已经开始故事或已经登录。
4. 页面里没有第一集草案正文。
5. 手机宽度没有横向滚动。

## 6. 框架之后的顺序

1. 确认主角名、作品标题、第一集正文。
2. 再接播放、选择、拍照和进度。
3. 最后才是付款和部署到 WorldAsGame.com。

说「开始开发」之后，只按第 2 节的目录搭这个外壳，不提前做第 4 节里的东西。
