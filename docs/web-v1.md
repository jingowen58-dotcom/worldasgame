# 第一版网站

> 域名：WorldAsGame.com。尚未开发。

第一版证明一件事：访客用手机打开网站，不注册就进入故事，做一个选择，提交一张照片，服务端把故事推进到下一段；关掉浏览器再打开，还停在原处。换一台设备继续，需要先绑定邮箱。

## 做

| 项 | 决定 |
|---|---|
| 页面 | 手机优先。首屏是这一部故事和开始按钮。没有第二部时不放空的作品卡片 |
| 进入 | 游客先玩。同一浏览器用 Cookie 恢复。保存进度或准备付款时，再用邮箱链接绑定 |
| 剧情 | 服务端运行 Ink。浏览器只提交选择标识和照片，不提交存档 |
| 版本 | 已开始的局钉在开局时的版本。改稿只影响新开的局 |
| 任务 | `photograph_anomaly`。一张合格照片即完成，不判断画面，不采集位置 |
| 账户 | 邮箱链接，不设密码。User、Identity、Session 分开。相同邮箱不自动合并不同登录方式 |
| 付费 | 可以先做未解锁占位。真实扣款不在这一版 |
| 数据 | 海外进度放在新的 PostgreSQL，只存网站用户和游客局 |

路径：

| 路径 | 作用 |
|---|---|
| `/` | 进入 The Other Side |
| `/play/[runId]` | 正文、选择、未解锁占位 |
| `/tasks/[challengeRunId]` | 提交照片 |
| `/login` | 只在保存进度或换设备时出现 |

刷新播放页时向服务端要进度再渲染。页面不保存「任务已完成」。

别人的 `runId` 不能读，也不能写。

## 不做

- 不读、不写微信小程序里的进度。
- 不做角色自由对话。
- 不做 Google、Apple 登录。
- 不做定位、图像识别、地图、小队、创作者后台、iOS。
- 不做月费和 99 美元权益包。
- 不把六集、证据板、关系值和分享卡放进这一版。
- 不新建另一套剧情格式。中文联调可以用现有故事证明管道，给用户看的版本必须是单独发布的英文稿。

## 真机验收

iPhone Safari 和一台 Android Chrome：

1. 不登录，打开 WorldAsGame.com，进入故事。
2. 做出一个选择。
3. 提交一张合格照片，看到下一段。换一张内容完全不同的合格照片，也会通过。不合格文件被拒绝。
4. 关掉浏览器再打开，同一台设备仍停在原处。
5. 绑定邮箱后，换一台设备，读到同一条进度。

对外开放之前还要有：确认过的英文正文、视觉稿、数据库和照片放在哪个区域、隐私说明和删除账号的入口。这些不挡住内部把链路跑通。
